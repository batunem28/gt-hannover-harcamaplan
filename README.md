# Harcamaplan GT Hannover

Schritt-für-Schritt-Formular für Planung und Abrechnung eines Programms von GT Hannover (Ortsverein Hannover Jugend | IGMG).
Am Ende gibt es die offizielle Harcama-Excel-Vorlage ausgefüllt zum Speichern.

Alles läuft im Browser. Eingaben werden nirgendwo hochgeladen, nur als Entwurf im eigenen Browser gemerkt.
