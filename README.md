# Ausgabenplan GT Hannover

Schritt-für-Schritt-Formular für Planung und Abrechnung eines Programms von GT Hannover (Ortsverein Hannover Jugend | IGMG).
Am Ende gibt es die offizielle Excel-Vorlage ausgefüllt zum Speichern.

- Läuft im Browser, auch auf dem Handy, ohne App.
- Der Entwurf wird nur im eigenen Browser gemerkt.
- Wer möchte, legt die Datei am Ende mit dem GT-Microsoft-Konto direkt in Teams ab (Team „GT Hannover“, Kanal SYK, Ordner der Abteilung › Programmformulare). Erst dabei wird etwas hochgeladen, und nur dorthin.
